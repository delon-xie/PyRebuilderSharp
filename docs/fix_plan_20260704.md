# Fix Plan Update - 2026-07-04

## Root Cause Fix Applied ✅

**process_data_file.3.11/3.13 无限循环根因**：

`BuildTryFromExceptionTable` 在 `handlerBody.Count == 0` 时，从 `visited` 和 `_processedBlockIds` 中移除了所有 try blocks 和 handler block（行 3253-3258）。这些 blocks 已在嵌套的内层 `BuildTryFromExceptionTable` 调用中正确消费了内部的 try/except/else/finally 结构。移除它们导致调用者的 successor 遍历（行 787）重新进入同一路径 → 无限循环。

修复：不再移除 visited。blocks 保持已访问状态，调用者跳过它们。

**反编译质量评**：process_data_file 的 3 层嵌套 try/except/else/finally + for/with 超出了当前 decompiler 的能力范围（独立于无限循环的已知局限）。属于 P0 comprehension + P1 try/except 恢复范畴。
