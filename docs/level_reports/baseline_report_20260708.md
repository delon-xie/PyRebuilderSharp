## 问题分类

### 🔴 P0: 控制流结构坍陷（~60% total diff）

**症状**: if-else 中 `return` 被吸入分支体，else/elif 体退化

```python
# 期望
if x > 0:
    result = "positive"
else:
    result = "non-positive"
return result

# 实际
if x > 0:
    result = 'positive'
    return result         # ← return 被吸入 if
result = 'non-positive'   # ← else 体在 if 之外
return result
```

**影响**: L1(100%), L7/L8/L9 全部 D 级。跨版本相同。

**根因**: `BuildIfElse`/`GetStructuredBlockStmts` 中后继 `Return` 被分支体吸收，而非作为 if-else 的 fallthrough。

**估算**: 5h

### 🟡 P1: 3.11+ try/except ET (~10% total diff)

**症状**: 3.11+ handler body 空白 → try/except 平坦化为顺序代码

**已修复**: l2_1/2/3/6/8 ✅。**剩余**: l2_4/5/10/11/12 — handler 后继因 orphan 块 Successors 为空而丢失。

**影响**: L2(100%), L10 中 try/except 密集文件(如 abc.py 的 C 级全丢失)。

**估算**: 3h

### 🟢 P2: Lambda 体为空 (~1%)

**症状**: lambda 体提取为空 → `lambda: None`

**根因**: `BuildLambda` 中 `DecompileChildCode` 返回空体 → `new Lambda(args, new Constant(null))`

**估算**: 1h
