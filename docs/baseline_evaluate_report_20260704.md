## 五、修复计划

### P0 - 控制块异常（最高优先级）

1. **修复 empty_try 问题（try 块无 except/finally）**
   - 问题: 反编译输出包含 `try:` 但没有 except/finally，总计 159 处，其中 3.14 占 66 处
   - 原因: 异常表解析和控制流图重建不完整，导致 try 块与 except/finally 块无法正确关联
   - 影响: 所有版本，是最大的单一类异常

2. **修复 try_no_except_finally 问题**
   - 问题: try 块后面直接出现 return/def 等语句，无 except/finally，总计 10 处
   - 原因: 异常处理块的后继分析不完整
   - 影响: 主要影响 2.7 和 3.10+ 版本

### P1 - 指令缺失

3. **修复列表推导式条件丢失问题**
   - 问题: 条件列表推导式 `[x for x in range(10) if x % 2 == 0]` 的 if 条件被丢失
   - 原因: POP_JUMP_IF_TRUE/FALSE 指令的条件提取逻辑不完整
   - 影响: 3.14 的列表推导式

4. **修复列表推导式重复输出问题**
   - 问题: 同一列表推导式被输出多次（如 `b = [x for x in range(10)]` 出现两次）
   - 原因: FOR_ITER 块被多次处理，_processedBlockIds 跟踪不完整
   - 影响: 3.14 的列表推导式

### P2 - 孤儿块

5. **修复 stray_pass 问题（多余 pass 语句）**
   - 问题: 在 if/for/while/return/def 前出现孤立的 pass 语句，3.14 占 37 处
   - 原因: 控制流图构建时块分类不准确
   - 影响: 所有版本，3.14 尤为严重

6. **修复 bare_list 问题（孤立的 `[]`）**
   - 问题: 输出中出现孤立的空列表字面量 `[]`，3.14 占 14 处
   - 原因: 列表推导式检测失败，BUILD_LIST 指令被当作独立表达式输出
   - 影响: 3.14 尤为严重

7. **修复 bare_elem 问题（孤立的 `elem`）**
   - 问题: 输出中出现孤立的 `elem` 标识符
   - 原因: 栈机状态管理问题

### P3 - 语法错误

8. **修复 3.14 列表推导式首元素丢失**
   - 问题: 第一个列表推导式 `a = [x for x in range(5)]` 完全丢失
   - 原因: 列表推导式检测逻辑在特定条件下跳过了首元素
   - 影响: 3.14 的列表推导式

9. **修复字符串格式化指令解析**
   - 问题: 出现 `'<10'(f" 失败{'<10'}...")` 等语法错误
   - 原因: BUILD_INTERPOLATION_314 等新指令处理不完整

### P4 - 优化

10. **加强 `_processedBlockIds` 处理**
    - 目的: 防止块被重复处理
    - 影响: 所有版本

11. **移除调试噪声** (`# orphan @` / `# [SUMMARY]`)
    - 改为 CLI 可选参数
    - 提升输出质量
